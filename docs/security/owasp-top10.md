# OWASP Top 10 (2021) mapping

How each category is addressed in Spine. "Evidence" points to code, a test or an ADR.
Status is updated during the Phase 3 security review.

| #   | Category                                 | Controls in Spine                                                                                                      | Evidence                                                                                                         |
| --- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| A01 | Broken Access Control                    | Deny-by-default route policies, hierarchical RBAC, server-side checks only, `not-found` for sensitive existence checks | [access.ts](../../apps/api/src/platform/http/access.ts), [rbac.md](rbac.md), http.test.ts, rbac-matrix test      |
| A02 | Cryptographic Failures                   | argon2id passwords, SHA-256-hashed refresh tokens at rest, HMAC-SHA256 webhooks, TLS at nginx, HSTS                    | [ADR-0016](../adr/0016-authentication-jwt-refresh-rotation.md), [auth.md](../modules/auth.md)                    |
| A03 | Injection                                | Kysely parameterized SQL, no eval in playbooks/scoring, ReDoS-guarded regex, Zod validation                            | [condition-eval.ts](../../packages/shared-schema/src/condition-eval.ts), [ADR-0013](../adr/0013-playbook-dsl.md) |
| A04 | Insecure Design                          | Threat model, ADRs, simulated adapters, approval gates for risky actions                                               | [threat-model.md](threat-model.md)                                                                               |
| A05 | Security Misconfiguration                | helmet headers, strict CORS allow-list, docs disabled in production, config validated at startup                       | [server.ts](../../apps/api/src/platform/http/server.ts), [config.ts](../../apps/api/src/platform/config.ts)      |
