# @spine/console

The analyst console: React 19 + Vite + TanStack Query + React Router, with hand-built
accessible components ([ADR-0023](../../docs/adr/0023-console-react-vite-no-ui-kit.md)).

```bash
pnpm --filter @spine/console dev     # http://localhost:5173 (proxies /api to :3000)
pnpm --filter @spine/console test
pnpm --filter @spine/console build
```

> **Status:** scaffold. Features land in Phase 1/2. See [docs/modules/console.md](../../docs/modules/console.md).
